
Objetivos 1. Señal de Reloj:o Tanto la escritura como la lectura deben operar con la misma señal de reloj.o No se realizarán operaciones de lectura o escritura en ausencia de un flanco de reloj.2. Operaciones Simultáneas:o La FIFO debe permitir la lectura y escritura simultánea en cualquier situación.o FIFO Vacía: Si se escribe y lee al mismo tiempo cuando la FIFO está vacía, se debe leer el mismo dato que se va a escribir tras el flanco de reloj activo.o FIFO Llena: Si la FIFO está llena, se debe evitar sobrescribir datos. El dato de DATA_IN se almacenará en la posición correspondiente y el dato de DATA_OUT se extraerá siguiendo el principio FIFO (First In, First Out).3. Situaciones Extremas:o FIFO Llena y Escritura sin Lectura: No se puede evitar la pérdida de datos en esta situación.o FIFO Vacía y Lectura sin Escritura: Tampoco se puede evitar la pérdida de datos en esta situación.o Las IPs comerciales de FIFOs adoptan dos enfoques:* No chequear estas situaciones y no tomar ninguna acción.* Chequear estas situaciones e impedir lecturas y escrituras, lo que ocupará más celdas lógicas pero no evitará la pérdida de datos en situaciones extremas.
Diseño de la FIFOMódulo FIFODescripción GeneralEl módulo FIFO implementa una memoria FIFO síncrona que permite operaciones simultáneas de lectura y escritura. Utiliza una máquina de estados finitos (FSM) para controlar el flujo de datos y un registro de desplazamiento (shifter_2d_var) para almacenar los datos.Entradas* DATA_IN: Entrada de datos de 8 bits que se escriben en la FIFO.* Read: Señal de control para leer datos de la FIFO.* Write: Señal de control para escribir datos en la FIFO.* Clear_n: Señal de borrado activo bajo.* RSTn: Señal de reset asincrónico activo bajo.* Clk: Señal de reloj.Salidas* F_FULL_N: Señal que indica si la FIFO está llena (activo bajo).* F_EMPTY_N: Señal que indica si la FIFO está vacía (activo bajo).* DATA_OUT: Salida de datos de 8 bits leídos de la FIFO.* USE_DW: Salida de 5 bits que indica el número de palabras usadas en la FIFO.Lógica Empleada* FSM: Controla los estados de la FIFO (vacía, llena, otros) y las señales de control (ENABLE, modo).* shifter_2d_var: Registro de desplazamiento que almacena los datos y permite operaciones de lectura y escritura basadas en las señales de control.
Módulo shifter_2d_varDescripción GeneralEl módulo shifter_2d_var es un registro de desplazamiento bidimensional que almacena los datos en una matriz y permite operaciones de desplazamiento y acceso directo a posiciones específicas.Entradas* clock: Señal de reloj.* reset: Señal de reset asincrónico.* enable: Señal de habilitación para operaciones de desplazamiento.* modo: Modo de operación (serie variable o fija).* seleccion: Dirección de selección para acceso directo.* entrada_serie: Datos de entrada de 8 bits.* clear: Señal de borrado activo bajo.Salidas* salida_serie: Datos de salida de 8 bits.Lógica Empleada* Registro de Desplazamiento: Almacena los datos en una matriz y permite desplazamientos basados en la señal de reloj y el modo de operación.* Acceso Directo: Permite escribir datos en una posición específica de la matriz cuando el modo es serie variable.
Módulo FSMDescripción GeneralEl módulo FSM es una máquina de estados finitos que controla el estado de la FIFO y las señales de control necesarias para las operaciones de lectura y escritura.Entradas* clk: Señal de reloj.* RSTn: Señal de reset asincrónico.* WRITE: Señal de control para escribir datos.* READ: Señal de control para leer datos.Salidas* F_FULL_N: Señal que indica si la FIFO está llena (activo bajo).* F_EMPTY_N: Señal que indica si la FIFO está vacía (activo bajo).* ENABLE: Señal de habilitación para operaciones de lectura/escritura.* modo: Modo de operación para el registro de desplazamiento.* Count: Contador de 5 bits que indica el número de palabras en la FIFO.Lógica Empleada* Estados: Define los estados de la FIFO (vacía, otros, llena, error) y las transiciones entre ellos.* Contador: Incrementa o decrementa el contador basado en las señales de lectura y escritura.* Señales de Control: Genera las señales de control (ENABLE, modo) necesarias para las operaciones de la FIFO.
